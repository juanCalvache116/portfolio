# Technical Portfolio & Simulation Showcase
### Juan Camilo Calvache Giraldo — Game Programmer & Simulation Developer

A high-performance, responsive, dark-mode technical portfolio showcasing gameplay mechanics, Unreal Engine 5 production simulators, VR interaction architectures, and physical hardware control integrations.

---

## ⚡ Quick Start

### 1. View Offline (Zero Setup)
Double-click `index.html` in Finder or Windows Explorer.

### 2. View with Local Web Server
```bash
# In this directory:
npm start
# or: npx serve .
```
Open `http://localhost:3000` in your browser.

---

## 🛠️ Architecture & Tech Stack

- **Core Web Standards**: HTML5, CSS3, ES6+ JavaScript.
- **Zero Build Overhead**: Edit content in `js/data.js` and see changes immediately without compilation.
- **Design System**: Studio Engine Slate with chromatic HUD accents (Cyan / Amber), responsive bento grids, and GPU-accelerated spring animations.
- **Deep-Dive Drawer Modals**: Interactive breakdowns for each project with live 1080p video demonstration integration, state diagrams, and verified code ownership evidence.
- **Adaptive Video Pipeline**: Embedded responsive YouTube video players with offline fallback conditioning.
